MAELEKEZO / INSTRUCTIONS - For a router with NO built-in WiFi, using a separate access point:

0. First, set your access point itself to bridge mode with its DHCP server turned off. If you have more than one access point, do the same for all. Two DHCP servers on one network will fight each other.

1. Plug your internet cable into . Plug your access point's uplink cable into ANY other port (2,4,5). Got more than one access point? Use a port for each, they all work.

2. Open the router's terminal (WinBox → New Terminal, or a phone browser to 192.168.88.1, or the MikroTik app)

3. Copy everything in the box above, paste it, then press Enter. After you press Enter it looks like nothing is happening for about 10 seconds - router is waiting for internet, then downloading rest of setup.

4. Wait a minute, then refresh this page. This site's status turns connected by itself.

Done. Your access point's WiFi now shows customers a login page.

Ukiisha ubandika wenyewe, si lazima ubonyeze kitu - you don't have to press anything.
